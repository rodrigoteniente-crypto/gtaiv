Para compilar, usá `ScriptHookDotNet.asi` de la instalación del juego como referencia,
o su copia llamada `ScriptHookDotNet.dll`. No hacen falta los componentes nativos
`ScriptHook.dll` ni `aCompleteEditionHook.asi` para compilar el código C#.

El paquete corregido usa los cargadores que ya están instalados. No redistribuye
ni reemplaza esos cargadores.
