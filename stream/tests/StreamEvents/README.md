Esta prueba usa las clases de producción de 1.9.1; sólo reemplaza el enum de teclas de Windows para poder ejecutarse en Linux.

```bash
dotnet run --project stream/tests/StreamEvents/StreamEvents.csproj -c Release
```

Verifica el delay de todos los tipos de eventos, overrides, orden, admisión acotada sin expulsar eventos importantes, expansión de regalos sin repetir efectos, entrada de la prueba de suscripción, arranque del director por spawn, duración proporcional de donaciones, aliases de Kick, cooldown por mensaje y cancelación del cliente.

La cámara, los personajes y el HUD necesitan validación dentro de GTA IV. La prueba de conexión sólo usa un puerto de loopback que rechaza conexiones.
